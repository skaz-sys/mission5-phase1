
# Mission 5 - Phase 1

## Trade Me Auction Search API

This project allows users to search for auction items
stored in a local MongoDB database.

## Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- Postman

## Installation

npm ci

## Seed auction data

npm run seed

## Delete auction data

npm run delete

## Start server

npm start

## API Endpoints

GET /auctions
GET /auctions?search=iphone

## Features

- Local MongoDB database
- CLI for adding and deleting auction data
- Keyword search by title and description
- Case-insensitive search
